## 실행 · 빌드

Node.js 20 이상 (개발 PC: Node 25.6, npm 11.9).

```bash
npm install
npm run build     # out/ 에 메인 · 화면 빌드
npm start         # 앱 실행 (VS Code 터미널이면 아래 주의)
npm test          # 단위 + 통합 시험
npm run lint      # 타입 검사
npm run dist      # Windows 설치파일 → release/글뚝딱-설치-0.1.0.exe
```

- **VS Code 안 터미널 주의**: VS Code 가 `ELECTRON_RUN_AS_NODE=1` 을 넣어 두어 `npm start` 가 "registerSchemesAsPrivileged" 오류로 멈춤. `env -u ELECTRON_RUN_AS_NODE npm start` (Git Bash) 또는 일반 터미널에서 실행. 설치본 사용자에게는 해당 없음.
- 시험 때 데이터 폴더를 따로 쓰려면 `GTD_DATA_DIR=폴더`.

### 보안 메모
- 화면 창: nodeIntegration 끔 · contextIsolation · sandbox · CSP, 앱 밖 이동 · 새 창 · webview 막음, 권한 요청 모두 거절. 외부 링크는 공식 주소 허용 목록만.
- 키: 등록 · 마스킹 보기 · 교체 · 삭제만. DB · 일반 설정 · 백업 · 로그에 원문 없음 (시험으로 확인).
- **한계**: safeStorage(DPAPI)는 평문으로 파일에 남지 않게 하는 것이고, 같은 Windows 계정으로 로그인한 사람(또는 그 계정에서 도는 프로그램)에게서 숨기는 절대 보호가 아님.
- 네이버 전용 창은 Playwright 로 연 별도 크롬/엣지 프로세스 — Node 권한 · 앱 키 · 로컬 문서에 접근하지 못함. 비밀번호를 받지 않고 평소 크롬 프로필을 복사하지 않음.

## 미검증 · 알려진 제한

1. **실제 OpenAI 호출 안 해 봄**: 글 생성 · 구조화 출력 · 이미지 생성. 기본 모델 이름(`gpt-6.1-sol`, `gpt-image-2.5-flare`)이 관장님 키로 되는지 [연결 확인]으로 먼저 확인 필요.
2. **실제 네이버 검색광고 조회 안 해 봄**: 서명 방식은 공식 샘플과 같음. 호출 한도 · 약관상 캐시 기간은 미확인 → 기본 24시간 재조회 간격(설정에서 0~168).
3. **실제 네이버 블로그 입력 안 해 봄**: 선택자는 1버전에서 2026-10월까지 쓰던 것. 네이버 화면이 바뀌면 `src/main/services/browser-draft/editor.ts` 부터 확인. 네이버 정책상 자동 입력 허용 범위도 재확인 필요. 네이버 임시저장 여부는 확인하지 않음(로컬 완료를 "네이버 저장 완료"로 표시하지 않음).
4. **코드 서명 안 됨** (`Get-AuthenticodeSignature` = NotSigned) → 설치할 때 Windows SmartScreen 경고가 뜰 수 있음. 앱 아이콘은 기본 Electron 아이콘.
5. 깨끗한 Windows 에 설치 · 제거(자료 삭제 질문), 업데이트 설치 시 자료 보존, 복원 후 자동 재시작 화면은 실제로 눌러 보지 않음 (복원 로직 자체는 단위 시험).
6. 브라우저: 앱에 넣지 않고 PC의 크롬(없으면 Windows 기본 엣지)을 씀 → 설치 용량 113MB, 오프라인에서도 앱은 열리지만 글 · 그림 · 키워드 · 네이버는 인터넷 필요.
7. 비용 추정: 요청 횟수만 기록하고 금액은 계산하지 않음 (단가 기준일 미확인). 실제 청구는 OpenAI 사용량 화면.
8. 다른 도장 프로필 여러 개: 데이터 모델은 가능하지만 화면은 기본 1개.
9. 아이 실제 사진을 이미지 API로 보내는 기능은 넣지 않음 (기본 일러스트, 사진은 네이버에 직접).
10. 앱 안 동영상 녹화는 범위 밖 — 타이핑 연출은 화면 녹화 도구로 촬영.

## API 설정 가이드

### OpenAI
1. platform.openai.com 로그인 → 결제 수단 · 크레딧 확인.
2. API keys → Create new secret key → 복사.
3. 글뚝딱 [설정] → OpenAI API 키 붙여넣기 → 저장 → [연결 확인].
4. 이미지 모델 권한 오류가 나면 카드는 [템플릿]으로 만들 수 있음.

### 네이버 검색광고 (선택)
1. searchad.naver.com 광고주 가입 · 로그인.
2. [도구] → [API 사용 관리] → 라이선스 발급 → **액세스 라이선스(API Key)**, **비밀키(Secret Key)** 복사.
3. **Customer ID**: SA API 사용 관리 화면 오른쪽 위 [검색광고 Key?] 를 누르면 나오는 숫자 (주소창 ad-accounts/ 뒤의 광고 계정 번호와 다름 — 2026-10-18 실사용에서 헷갈렸음).
4. 글뚝딱 [설정]에 셋 다 저장 → [연결 확인].
5. 없으면 새 글 화면에서 키워드를 직접 적으면 됨.

### 카카오 로컬 (선택, 동네 이름)
1. developers.kakao.com → 내 애플리케이션 → 앱 만들기 → 앱 키의 **REST API 키**.
2. 글뚝딱 [설정]에 저장 → [도장 정보]에 상세 주소 저장 → [카카오로 주변 찾기].

### 네이버 블로그
1. [도장 정보]에 블로그 주소(`https://blog.naver.com/아이디`).
2. [설정] → [브라우저 열기 · 로그인] → 열린 창에서 직접 로그인(2단계 인증도 직접).
3. 글 화면 → [네이버에 초안 입력] → 네이버 창에서 확인 → 직접 저장 · 발행.
